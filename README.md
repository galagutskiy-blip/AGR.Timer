# МКС Таймер — PWA

Это версия приложения для GitHub Pages. Она устанавливается на телефон как PWA.

## Структура
- `index.html` — приложение
- `manifest.webmanifest` — описание устанавливаемого приложения
- `sw.js` — офлайн-кэш и запуск без сети
- `icons/` — иконки приложения

## GitHub Pages
1. Загрузите все файлы и папку `icons` в репозиторий.
2. В GitHub откройте **Settings → Pages**.
3. Включите публикацию из нужной ветки (обычно `main`, папка `/root`).
4. Откройте выданный HTTPS-адрес.

## Установка на Android
Откройте сайт в Chrome → меню `⋮` → **Установить приложение** / **Добавить на главный экран**.

## Установка на iPhone
Откройте сайт в Safari → **Поделиться** → **На экран «Домой»** → **Добавить**.

Важно: GitHub Pages должен открываться по HTTPS. Локальный `file://` режим не активирует PWA.
